# Карась и коты

Небольшой Fabric-мод о Карасе и его пушистых друзьях для Minecraft Java Edition **26.3**.

## Уход за кошками

У каждой приручённой кошки есть сохраняемые показатели **сытости**, **настроения** и **ухоженности**. Пока игровой мир работает, раз в игровой день кошка теряет 20 сытости, 8 настроения и 8 ухоженности. Значения отображаются от 0 до 100; низкие показатели сами по себе не наносят кошке урон.

Используйте предмет на своей приручённой кошке:

- **Лакомство Карася** приручает бездомную кошку. Для своего питомца оно даёт до 45 сытости и 5 настроения, а также лечит 4 единицы здоровья, если кошка ранена. Чужих питомцев лакомство не затрагивает.
- **Игрушка для кота** поднимает настроение на 30, но игра немного утомляет кошку и снижает сытость на 3. Использовать игрушку можно раз в 30 секунд.
- **Щётка для кота** повышает ухоженность на 35 и настроение на 8. Вычесывать кошку можно раз в минуту.
- **Дневник ухода за котом** показывает текущие три показателя и ничего не расходует.

Показатели хранятся отдельно у каждой кошки и сохраняются вместе с миром. Все предметы доступны во вкладке **«Ингредиенты»** в творческом режиме.

## Карась и медальон

- **Медальон Карася** — примените его к своей приручённой кошке, чтобы дать ей имя «Карась».
- Добавлен отдельный вариант кошки **Карась**: белая шерсть, серые отметины, розовые ушки и нос, глаза янтарно-зелёных оттенков. Он может появляться среди обычных кошек; у котят тоже своя текстура.

Чтобы призвать кошку с окрасом Карася (нужны включённые команды), используйте:

```mcfunction
/summon minecraft:cat ~ ~ ~ {variant:"karas_cats:karas"}
```

## Профили котов-подписчиков

Для каждого окраса можно добавить отдельный профиль с именем, ником подписчика, описанием и характеристиками от 0 до 100. Характеристики влияют на скорость, урон атаки и броню; профиль Карася — **ловкость 20, сила 95, защита 90**, то есть он сильный и стойкий, но медленный. Дневник ухода показывает профиль кота.

Новые профили и окрасы добавляются ресурсными JSON-файлами и текстурами — отдельный Java-код для каждого кота не нужен. Шаблоны и инструкция по размерам текстур лежат в [`docs/CAT_PROFILES.md`](docs/CAT_PROFILES.md) и `docs/templates/`. Новые профили перечитываются при старте мира и командой `/reload`. Команда `/karas profiles` показывает загруженные варианты, рейтинги и готовую команду призыва.

## Рецепты

- Лакомство: сырая треска + сырой лосось + ламинария → 2 лакомства.
- Медальон: золотой самородок + сырой лосось + нить → 1 медальон.
- Игрушка: нить + серая шерсть + перо → 1 игрушка.
- Щётка: палка + 2 нити + железный самородок → 1 щётка.
- Дневник ухода: книга + бумага + перо → 1 дневник.

## Сборка

Требуется **JDK 25 или новее**. Из корня проекта запустите:

```bash
./gradlew build
```

В Windows:

```bat
gradlew.bat build
```

Готовый файл появится в `build/libs/`. Для игры нужны Minecraft 26.3, Fabric Loader и Fabric API.
