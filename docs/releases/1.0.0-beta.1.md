# Карась и коты 1.0.0-beta.1

Первый предварительный релиз мода для **Minecraft Java Edition 26.3 / Fabric**. Это beta для тестирования, не проверенный в игре стабильный релиз. Перед использованием в существующем мире сделайте резервную копию.

## Что входит

- Карась со взрослой и детской текстурами; расширяемые JSON-профили котов-подписчиков.
- Лакомство, медальон, игрушка, щётка и дневник ухода с рецептами.
- Сохраняемые потребности: сытость, настроение и ухоженность. Низкие потребности сами по себе не ослабляют и не повреждают кота.
- Сохраняемая привязанность: +2 за успешное использование лакомства, +5 за игру, +3 за вычёсывание. Она не убывает и видна в дневнике.
- У старых сохранений без поля привязанности начальное значение 0; награды защищены от переполнения.
- Профили с ловкостью, силой и защитой, просмотр через `/karas profiles` и обновление через `/reload`.
- 15 автоматических тестов ухода, привязанности и формата сохранения; проверка профилей и размеров текстур.

## Требования

- Minecraft **26.3**.
- Fabric Loader **0.19.5 или новее**.
- Fabric API для Minecraft 26.3; при сборке используется **0.162.0+26.3**.
- Java **25**.

## Установка

1. Установите Fabric Loader для Minecraft 26.3.
2. Положите `karas-cats-1.0.0-beta.1.jar` и подходящий Fabric API в папку `mods`.
3. Для проверки в сетевой игре установите мод и зависимости также на Fabric-сервер.
4. Запустите игру и найдите предметы мода во вкладке «Ингредиенты» или создайте их по рецептам из README.

Файл `-sources.jar` содержит исходники — его **не нужно** класть в `mods`. `SHA256SUMS` содержит контрольные суммы JAR-файлов; `BUILD_INFO.txt` указывает коммит, зависимости, результат unit-тестов и сборку GitHub Actions.

## Проверки и ограничения

- Релизные файлы прикладываются только после успешной сборки и выполнения всех unit-тестов в GitHub Actions на JDK 25.
- Ручные сценарии клиента, выделенного сервера и обновления существующего мира пока не подтверждены; инструкция — в `docs/TESTING.md`.
- Дневник пока выводит данные в чат, а не в отдельное окно.
- Тренировочные очки, защита владельца, уникальные пассивные способности, наследование характеристик, могилка и воскрешение **ещё не реализованы**.
- Текущий отсчёт снижения потребностей начинается заново после успешного ухода: частый уход может откладывать снижение остальных показателей. На здоровье и привязанность это не влияет.

Дальнейшая разработка идёт по согласованной `ROADMAP.md`; отдельная экипировка в план этого этапа не входит.
