# Профили котов-подписчиков

Система разделяет внешний вид и игровой профиль кота. Каждый вариант окраса Minecraft имеет ID вида `namespace:id`; файл профиля с тем же ID задаёт имя, описание и три рейтинга от 0 до 100. Новые профили загружаются при старте мира и после `/reload`.

Для добавления кота с ID `subscriber_cat` нужны файлы:

1. `src/main/resources/data/karas_cats/cat_variant/subscriber_cat.json` — вариант окраса. Можно скопировать `docs/templates/cat-variant.json`.
2. `src/main/resources/data/karas_cats/cat_profile/subscriber_cat.json` — описание и рейтинги. Можно скопировать `docs/templates/cat-profile.json`.
3. `src/main/resources/assets/karas_cats/textures/entity/cat/subscriber_cat.png` — взрослая текстура **64×32**.
4. `src/main/resources/assets/karas_cats/textures/entity/cat/subscriber_cat_baby.png` — текстура котёнка **32×32**.

ID должен совпадать в двух JSON-файлах. Вариант окраса указывает на текстуры через `asset_id` и `baby_asset_id`. После добавления текстур обновите ресурсы клавишами **F3+T**; профили перечитаются через `/reload`. Для проверки кота можно призвать командой:

```mcfunction
/summon minecraft:cat ~ ~ ~ {variant:"karas_cats:subscriber_cat"}
```

## Характеристики

Все рейтинги задаются числами от 0 до 100:

- **Ловкость** меняет скорость передвижения относительно обычного кота: 50 — без изменения, 20 — примерно на 30% медленнее, 80 — примерно на 30% быстрее.
- **Сила** меняет урон кошачьей атаки: 50 — без изменения; каждые 25 пунктов выше/ниже 50 добавляют/убирают примерно 1 единицу урона.
- **Защита** переводится в броню Minecraft: каждые 20 пунктов дают 1 очко брони.

Профиль Карася уже служит примером тяжёлого бойца: **ловкость 20, сила 95, защита 90**. Кошки без специального JSON-профиля получают нейтральный профиль и сохраняют обычную скорость и силу.

Профиль связан именно с вариантом окраса: все кошки одного subscriber-варианта имеют эти характеристики. Дневник ухода показывает имя, описание и рейтинги профиля вместе с потребностями кошки. Команда `/karas profiles` выводит загруженные профили, их характеристики и готовые команды для призыва.

Перед сборкой проверь новые профили и текстуры командой из корня проекта:

```bash
python3 tools/validate_cat_profiles.py
```

Проверка сверяет ID профиля и окраса, диапазоны характеристик, PNG-файлы и размеры взрослых/детских текстур.

## Как подготовить заявку для добавления кота

Пришли мне:

- фотографию кота, желательно с хорошо видимыми окрасом и отметинами;
- имя кота и ник подписчика (если его нужно указать в профиле);
- короткое описание характера;
- пожелания по стилю — например, «ловкий, но слабый», «сильный танк» или конкретные рейтинги.

Я подготовлю взрослую и детскую pixel-art текстуры, добавлю файлы варианта и профиля, а также проверю JSON и размеры изображений. Для следующих котов новый Java-код не требуется.
